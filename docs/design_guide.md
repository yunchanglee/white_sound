# 쉼 (Hush) — 디자인 가이드 v1.0

## 1. 브랜드 원칙

| 원칙 | 의미 | 디자인 적용 |
|---|---|---|
| **고요함 (Calm)** | 화면도 소리처럼 조용해야 함 | 다크 퍼스트, 낮은 채도, 큰 여백, 느린 모션 |
| **바로 (Instant)** | 졸린 상태에서도 1탭이면 재생 | 홈 맨 위 ‘이어서 듣기’, 큰 터치 영역 |
| **따뜻함 (Warm)** | 차가운 기계음이 아닌 곁에 있는 소리 | 달빛 크림색 강조색, 둥근 모서리, 부드러운 말투 |

**키 비주얼**: 밤하늘 남색 위에 뜬 초승달, 그리고 달에서 풀려 나오는 소리 물결

### 2.2 분류 색상
| 분류 | 토큰 | HEX | 배경 그라디언트 |
|---|---|---|---|
| 🌙 깊은 잠 | `sleep` | `#9C9CFF` | `#2D3A75 → #0E1126` |
| 🎯 집중 | `focus` | `#4FD1C5` | `#1C4A52 → #0E1126` |
| 📖 공부 | `study` | `#A8D672` | `#1F4A3E → #0E1126` |

- 분류 색은 **점(dot), 진행 링, 플레이어 배경**에만 씁니다. 큰 면적에 채도 높은 색을 칠하지 않습니다.
- 사운드 타일: 소리의 재질을 담은 **150° 2색 그라디언트** (예: 빗소리 `#3B4A85→#1E2550`, 불 `#A4553A→#4A2230`).

### 2.3 라이트 테마 (선택)
낮에 쓰는 집중·공부용. `bg #F5EEDC`, `surface #FFFFFF`, `primary #2E3A6B`, `text #1B1F3B`. 기본값은 **시스템 설정 따르기**이고, 22시~06시에는 항상 다크로 표시하는 옵션을 제공합니다.

> [!IMPORTANT]
> 수면 화면에서는 순수 블랙 `#000000`과 아주 어두운 텍스트(`#6C6F8C` 이하)만 씁니다. 밝은 흰색은 수면을 방해합니다.

## 3. 타이포그래피
- 서체: **Pretendard** (한글·영문 모두, OFL 무료). 대체 서체는 Noto Sans KR
- 숫자(타이머/시계): Pretendard `tnum`(고정폭 숫자). 큰 시계는 Light 200~300

| 스타일 | 크기 / 행간 | 굵기 | 용도 |
|---|---|---|---|
| Display | 52 / 60sp | Bold | 포모도로 남은 시간 |
| Clock | 64~84sp | Light | 잠금화면, 수면 화면 시계 |
| Headline | 24 / 32sp | Bold | 화면 제목, 사운드 이름 |
| Title | 18 / 26sp | Bold | 시트 제목, 카드 제목 |
| Body | 14 / 21sp | Regular | 설명 |
| Label | 13sp | Medium | 칩, 버튼 |
| Caption | 12 / 18sp | Regular | 보조 정보 |
| Tile | 14sp Bold + 11sp | — | 사운드 타일 |

## 4. 간격 · 모서리 · 그림자
- **4dp 그리드**. 화면 좌우 여백 20dp, 카드 내부 여백 16~18dp, 요소 간격 8 / 12 / 16 / 20dp
- 모서리: 칩·버튼 = 완전히 둥글게(pill) / 사운드 타일 20dp / 카드 24dp / 바텀시트 상단 28dp / 아이콘 마스크는 시스템 기본
- 그림자 대신 **표면 색의 단계(tonal elevation)**로 높이를 표현. 강조 요소에만 은은한 글로우 (`0 0 60px rgba(156,156,255,.35)`)

## 6. 앱 아이콘 & 백그라운드 재생 아이콘

### 6.1 런처 아이콘 — “달의 물결”
- **콘셉트**: 초승달의 아랫부분이 세 갈래 소리 물결로 풀려 나갑니다. **밤(잠) + 소리(노이즈) + 흐름(집중)**을 한 형태로 담았고, 앰버색 별 하나가 따뜻한 포인트입니다.
- **규격**: Adaptive Icon 108dp. 그래픽은 중심 66dp 안전 영역 안에 둡니다. 배경 레이어는 `#1B1F3B → #2E3A6B` 세로 그라디언트, 전경은 `#F5EEDC`
- **Android 13+ 테마 아이콘**: 같은 실루엣을 단색으로 제공 (`monochrome` 레이어)
- Play 스토어용: 512×512 PNG

### 6.2 상태바 / 알림 아이콘 (백그라운드 재생)
| 파일 | 상태 | 형태 |
|---|---|---|
| `ic_stat_playing` | 재생 중 | 초승달 + 물결 2줄 |
| `ic_stat_timer` | 자동 꺼짐 예약 중 | 시계 + 물결 2줄 |

- 24dp, **흰색 단색 + 투명 배경** (Android는 알파 채널만 사용). 선 굵기 1.9dp, 가장자리 여백 2dp 이상
- 런처 아이콘의 ‘달+물결’을 줄인 형태라 상태바에서도 같은 앱임을 알아볼 수 있습니다.
- 알림 accent color는 `#2E3A6B`, 미디어 알림의 큰 이미지는 사운드 타일 그라디언트 아트를 사용합니다.

## 7. 모션
| 상황 | 모션 |
|---|---|
| 기본 전환 | 300~400ms, `EaseInOutCubic`. 빠르게 튀는 애니메이션은 쓰지 않음 |
| 브리딩 오브 (플레이어) | 4초 들숨 → 6초 날숨 반복, scale 0.92 ↔ 1.0, 글로우 투명도 0.25 ↔ 0.45 |
| 재생 / 일시정지 | 아이콘 모핑 200ms + 볼륨 페이드 인 1.5초 |
| 타이머 종료 | 볼륨 페이드아웃과 함께 화면 밝기도 서서히 낮아짐 |
| 수면 화면 | 60초마다 시계 위치를 ±12dp 이동 (번인 방지) |
| 동작 줄이기 | 시스템 ‘애니메이션 삭제’가 켜져 있으면 브리딩 오브를 정지 이미지로 대체 |

## 8. 접근성
- 텍스트 대비 4.5:1 이상 (`text2`까지 통과, `text3`는 장식용으로만)
- 터치 영역 최소 48dp. 재생 버튼은 56~80dp
- TalkBack: 타일 = “잔잔한 빗소리, 깊은 잠, 재생 중, 두 번 탭하여 일시정지”. 타이머 = “42분 후 꺼짐”
- 글자 크기 200%에서도 레이아웃이 깨지지 않도록 타일은 최소 높이만 정하고 늘어나게 함
- 색만으로 정보를 전달하지 않음 (분류 = 색 점 + 텍스트)

## 9. 보이스 & 톤
- 반말이 아닌 **부드러운 해요체**, 짧게. 예) “오늘도 푹 쉬어요”, “내일 오전 2:30에 꺼져요”
- 시간대별 인사: 05–11 “상쾌한 아침이에요” / 11–18 “집중할 시간이에요” / 18–22 “편안한 저녁이에요” / 22–05 “좋은 밤이에요 🌙”
- 금지: 의학적 효능 단정(“불면증 치료”), 느낌표 남용, 불안을 자극하는 문구
